# Shared terms

- Design harness: the shared instructions, component map, and review rules
  used to guide AI work in an app repo.
- Design system: the approved visual rules and reusable UI parts.
- Component: a reusable React UI part with defined props and states.
- Token: a named design value, such as a color or spacing value.
- Screen: a rendered view built from the app's components.
- Flow: the steps a person takes to complete 1 task across screens or states.
- Pilot: a small trial that checks the workflow before a team uses it widely.
- Slice: the smallest complete user-visible change that can be checked.
- Design approval: the designer accepts the rendered result against the brief.
- Engineer approval: the engineer accepts the code and its checks for integration.

Architecture terms such as module, interface, and seam keep their definitions
in `.agents/skills/codebase-design/SKILL.md`. Use component for React UI parts.
