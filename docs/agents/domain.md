# Domain docs

Read `CONTEXT.md` before exploring. It is the shared glossary. Read relevant
approved decisions in `docs/adr/` when they exist. Proceed when that directory
is absent. Create an ADR only for an approved decision that needs its reasons
preserved. Keep app setup, evidence, and task status outside the glossary.

The target app's own glossary and decisions take precedence when the harness
is adopted. Resolve a conflict before editing its code.
