# Task labels

| Skill role | Local status | Meaning |
| --- | --- | --- |
| needs-triage | needs-triage | Review the request. |
| needs-info | needs-info | A required answer is missing. |
| ready-for-agent | ready-for-build | The work is clear enough to start when asked. |
| ready-for-human | ready-for-human | A person must take the next step. |
| wontfix | wontfix | The work will not proceed. |

`ready-for-build` does not start agents or grant publication approval.
In an adopted app, map these roles to the real tracker's existing labels.
